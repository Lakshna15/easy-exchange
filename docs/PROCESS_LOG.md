# Process log

One entry per step, newest at the bottom. Record what happened, including what went wrong.

## Entry format

```
## YYYY-MM-DD — <phase and step, for example "Phase 1.1 Challenge the plan">

- Mode: Plan | Agent | Ask
- Skills: <name (native | imported | project)>, ...
- Prompt: <one or two sentences, or a link to the playbook step>
- Produced: <files created or changed, commit hash>
- Changed or rejected: <what I corrected, refused or re-prompted, and why>
- Learned: <what I would do the same or differently next time>
```
